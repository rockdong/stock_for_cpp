## ⚠️ 测试注意事项

### 环境要求

**必须配置的环境**:
1. `.env` 文件（完整配置）
2. 数据库连接（MySQL 或 SQLite）
3. TuShare API Token（数据源）
4. 股票列表数据（stock_basic 表）

**可选配置**:
1. 市场热度数据接口
2. 自定义策略配置
3. 日志级别和路径

### 测试风险

**潜在问题**:
1. 数据源 API 限制（TuShare 有调用频率限制）
2. 数据库性能（大量数据插入）
3. 网络稳定性（数据获取依赖网络）
4. 内存限制（多线程并发消耗）

**应对措施**:
1. 使用本地缓存数据测试
2. 使用 SQLite 避免数据库性能问题
3. 减少测试股票数量
4. 监控内存使用情况
